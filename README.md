# How the Program Works:
The system operates on a simple calculation loop:
Tax Deduction: It automatically deducts a 15% tax
from all calculated salaries.

Smart Validation: The program prevents you from accidentally
using the same Employee ID twice and blocks you 
from viewing records if the system is empty.

# Step-by-Step User Guide
## 1. Adding a New Employee (Option 1)
  1. Type 1 at the main menu
     and press Enter.
  2. Provide the requested details when
     prompted:  Name (e.g., John Doe)  Hours Worked (e.g., 40)
     Rate of Pay (e.g., 200)  Employee ID Number (e.g., EMP001)
  3. If you type an ID that already exists, the system will
     gently warn you and ask for a unique one.
  4. Tip: Typing 00 as the ID will safely exit the
     creation menu.

## 2. Viewing Employee Records (Option 2)
   1.Type 2 at the main menu and press Enter.
     (Note: This only works if you have added at
     least one employee).
   2. Enter the Employee ID you want to look up.
   3. The screen will instantly display:
      The employee's name.
      Total hours worked.
      Their final Net Salary (after tax).
      The Average Salary of all employees currently
      in the system.
   5. Press any key to return to the main menu.
